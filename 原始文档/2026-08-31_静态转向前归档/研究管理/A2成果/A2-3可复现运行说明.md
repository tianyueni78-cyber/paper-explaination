# A2-3 可复现运行说明

- 成果版本：v1.0
- 固定代码：`Python-NEW@baseline-matlab-observed-v1.0`
- 用途：重新生成规定格式的Python结果，并追溯至代码、配置、种子和原始输出

## 运行前提

1. 检出`Python-NEW`仓库标签`baseline-matlab-observed-v1.0`。
2. 按仓库环境说明安装Python依赖，使用仓库内的`python_baseline/data/`数据和JSON配置。
3. 保留每次运行的随机种子、命令、配置、输出目录和代码提交。

## 最小验证入口

```powershell
python scripts/check_step13.py
python -m unittest discover -s tests -v
```

第一条用于复核Gate 1–6及固定指标参考；第二条用于运行当前标签下的全量自动测试。冻结报告记录的验收结果为101项通过；若未来标签上的数量不同，应先检查是否检出了正确提交。

## 论文级批量入口

```powershell
python scripts/run_step14_static.py --output results/runs/step14_static_formal
python scripts/run_step14_dynamic.py --output results/runs/step14_dynamic_formal
```

两个入口分别用于静态和动态批量实验。如只需冒烟复核，可依据[第14步运行说明](https://github.com/tianyueni78-cyber/Python-NEW/blob/main/reproduction/14_%E8%AE%BA%E6%96%87%E7%BA%A7%E9%87%8D%E5%A4%8D%E5%AE%9E%E9%AA%8C/%E7%AC%AC14%E6%AD%A5%E8%BF%90%E8%A1%8C%E8%AF%B4%E6%98%8E.md)限定实例、场景和重复次数。

## 输出与追溯要求

| 内容 | 必须保存的信息 |
|---|---|
| 代码 | 仓库、commit和tag |
| 环境 | Python版本和依赖版本 |
| 输入 | 实例、事件、策略、参数与配置路径 |
| 随机性 | 每次运行的种子，不允许只保留有利运行 |
| 结果 | 原始运行输出、汇总表、成功/失败/超时状态 |
| 完整性 | 结果数量、文件哈希、预期字段和审计报告 |

原始大体量结果不强制上传GitHub，但必须保存其目录、数量、哈希、最小证据和可重运入口。原作者未公开的历史逐代日志不是验收条件；从本基线起，Python新运行必须产生自己的日志。

## 预期结果

运行包能重建规定格式的Python输出，并复核Gate和实验文件完整性。它不保证生成与论文相同的随机轨迹或统计排名；这一限制已由Gate 7结论显式记录。
