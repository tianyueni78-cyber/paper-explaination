更新日期：2026年8月30日

# 第1页｜研究问题与论文故事

## 1. 研究背景

原QNSGA-II由NSGA-II负责全局种群演化，Q-learning从N1–N6中选择局部邻域，机器–AGV领域解码器负责生成调度并计算Makespan和能耗目标。

N1–N6主要解决“如何修改染色体”，但动态事件发生后，算法还需要回答：哪些任务不能修改，哪些剩余工序最值得搜索，以及有限响应时间应投入多少候选评价。

需要特别说明的是，原算法的静态核心使用Q-learning选择N1–N6；但冻结MATLAB动态活动路径没有在订单取消、机器故障和AGV故障中统一启用该机制。因此，把Q-learning/N1–N6接入三类动态事件属于本文拟验证的新增行为，不是baseline原本已经完整具备的功能。

## 2. 研究问题

> 在不改变问题模型、数据、染色体、动态约束、目标函数、解码器和NSGA-II主体的前提下，如何根据动态事件后的合法边界、资源瓶颈和剩余计算预算，自适应分配局部搜索区域、邻域类型与候选评价数量，从而提高动态重调度的质量–时间效率？

## 3. 论文场景

动态重调度不仅是一个调度优化问题，也是有限搜索计算资源如何配置的问题。原算法主要学习“使用哪种邻域”，本文进一步研究动态事件发生后“允许搜索哪里、重点搜索哪里、怎样搜索以及投入多少计算资源”。

本文不重新建立机器–AGV调度模型，不发明新的强化学习算法，也不使用求解器替代QNSGA-II。本文的研究位置是：

> 在原QNSGA-II问题模型和多目标进化框架之上，增加一个面向动态事件的自适应局部搜索资源控制层。

# 第2页｜原算法与创新算法的差异

## 1. 四项新增内容

### （1）动态合法搜索边界

根据订单取消、机器故障或AGV故障的继承约束，确定`fixed`、`residual`、可修改染色体片段和当前合法邻域子集。

该模块回答“哪些内容允许修改”。`fixed/residual`本身来自baseline；本文新增的是将这些边界转化为Q-learning可以使用的合法动作集合。因此，它是可执行性基础，不单独承担主要创新主张。

### （2）瓶颈感知的Top-K局部搜索区域

利用事件后的解码结果计算机器加工压力或AGV运输压力，在`residual`中选择对当前瓶颈贡献较大的Top-K工序。

该模块回答“当前最值得搜索哪些工序”。Top-K不是新邻域，而是限制N1–N6主要作用在哪些工序上。

### （3）预算感知的Q-learning复合决策

保留原Q-learning和N1–N6，但将Q-learning的动作从“只选择邻域”扩展为联合选择：

- Top-K区域规模；
- 当前合法的N1–N6邻域；
- 候选评价预算。

状态拟包含事件类型与阶段、瓶颈类型与严重程度、搜索停滞和剩余预算；奖励拟同时考虑Pareto改善、评价成本和不可行候选。

该模块回答“在哪里搜索、怎样修改、投入多少计算量”，是当前最关键但仍待Oracle验证的算法创新候选。

### （4）结果一致的并行候选评价

候选染色体生成后，并行调用同一个动态解码器计算目标。Q表更新、种群合并和NSGA-II环境选择仍串行执行。

该模块回答“如何缩短候选评价等待时间”。它承担动态响应效率增强，不单独承担解质量创新主张。

## 2. 改动边界

| 算法层次 | 本文处理 |
|---|---|
| 问题、数据与三类动态事件 | 不改变 |
| OS、MS、AS、VS染色体 | 不改变 |
| 动态状态继承与调度解码器 | 不改变 |
| Makespan与TEC定义 | 正式实验使用冻结baseline的统一定义 |
| NSGA-II主体 | 不改变 |
| N1–N6基本修改含义 | 保留，但限制作用范围 |
| 动态局部搜索控制层 | 新增合法动作、Top-K、复合动作与质量–成本奖励 |
| 候选评价 | 评价规则不变，增加并行执行 |

# 第3页｜初步可行性证据

## 1. 探针实验合同

当前探针统一使用Mk05固定参考染色体、机器故障事件、RS重调度策略和AS修改动作。各对照保持初始解、事件、区域规模或预算、候选生成规则及解码器一致。

这些实验只用于判断方法是否值得继续实现，不是完整算法优于baseline的论文级证据。

## 2. 核心结果

| 验证问题 | 主要结果 | 当前判断 |
|---|---|---|
| 瓶颈区域是否优于同规模随机区域 | Top-5平均支配改善率53.6%，随机区域35.2%；瓶颈区域胜7/10 | 瓶颈区域值得继续研究 |
| 区域是否越大越好 | 同为50次评价时，Top-5改善率51.6%，Top-10为29.6%；Top-5胜10/10 | 有限预算下集中搜索可能更有效 |
| 预算是否影响质量和时间 | 预算10/50/200时，平均最佳Makespan为2903.60/2797.76/2771.29，时间约0.01/0.06/0.26秒 | 存在可观测的质量–成本权衡 |
| 并行评价是否可行 | 相同1000个候选使用2/4进程，平均加速约1.46/1.59，目标值与顺序一致 | 并行评价技术可行 |
| Q-learning是否已经有必要 | 6个机器故障状态的当前Oracle最优动作集合未变化 | 尚无证据支持Q-learning必要性 |
| Top-K相对原邻域是否有增量 | 相同AS单点修改下，Top-5改善率64.6%，原N5为22.4%；Top-5胜10/10 | 区域限制具有继续验证价值 |
| 求解器修复是否应纳入 | 求解器可合法接入，但改善率35%，低于启发式52%，仅胜1/10 | 当前求解器模型停止纳入 |

## 3. 当前证据边界

- 当前主要是单实例、少量状态的P1级探针；
- 尚未运行冻结baseline下的完整算法比较与消融；
- 探针第二目标使用临时`machine_energy`，不能直接写成正式TEC结论；
- 尚未完成HV、IGD、统计显著性、效应量和多事件验证；
- 因此只能声称“具有继续研究的可行性”，不能声称“完整方法已经显著优于原算法”。

# 第4页｜文献位置与当前新颖性判断

## 1. 已有研究覆盖的相邻机制

| 已有研究 | 已经覆盖的机制 | 本文不能单独声称的内容 |
|---|---|---|
| 原QNSGA-II、D2NSGA-II、L041 | 学习器选择局部邻域 | Q-learning选择邻域不是首次提出 |
| D2NSGA-II | 关键路径、关键块和问题驱动局部搜索 | 根据问题特征限制搜索对象不是空白 |
| L037 | Q-learning选择知识区域 | Q-learning选择区域不是首次提出 |
| L033、L035、L044 | 参数自适应、停滞状态和搜索强度调整 | 自适应参数或停滞控制不能单列为创新 |
| L043 | 根据状态构造合法工序–机器–AGV联合动作 | 合法动作集合不是首次提出 |
| L040及相关并行研究 | 并行遗传操作或并行环境 | 并行本身不能作为解质量创新 |

## 2. 当前可辩护的方法差异

在目前28篇本地语料、公开摘要和D2NSGA-II正文覆盖范围内，尚未发现一项研究在原QNSGA-II的动态局部搜索位置同时实现：

1. 由三类动态事件的任务继承和重调度权限形成合法动作空间；
2. 由事件后机器或AGV负载形成Top-K残余工序区域；
3. 由Q-learning联合选择合法邻域、区域规模和候选评价预算；
4. 使用Pareto质量增量、评价成本和不可行率共同反馈动作；
5. 仅并行固定候选的原动态解码，保持Q更新和NSGA-II选择串行。

因此，当前可辩护的不是四个模块分别首次提出，而是它们在动态QNSGA-II局部搜索位置形成的联合机制及质量–时间控制目标。

## 3. 新颖性结论边界

当前文献工作达到叙述性小论文的可追溯机制筛查标准，但没有正式数据库检索导出。因此：

- 可以说“在当前可获得证据范围内尚未发现相同联合机制”；
- 不得声称“全球首次”；
- 不得跨论文直接比较目标数值；
- 后续仍需持续核查最新近邻研究。

# 第5页｜完整算法流程与验证逻辑

## 1. 完整流程

1. 输入当前种群、动态事件、重调度策略、剩余评价预算和Q表。
2. 调用冻结baseline分析事件，获得`fixed`、`residual`、资源继承状态和可修改片段。
3. 根据动态边界生成当前合法的N1–N6子集。
4. 使用当前代表解的解码结果计算机器和AGV剩余负载。
5. 在`residual`中计算工序的瓶颈贡献并生成Top-K候选区域。
6. 根据事件、瓶颈、停滞和剩余预算组成Q-learning状态。
7. Q-learning从合法复合动作中选择邻域、区域规模和评价预算。
8. 只在选定区域内执行邻域并生成带编号的候选染色体。
9. 并行调用原动态解码器评价候选，按编号恢复结果顺序。
10. 根据共同尺度下的Pareto质量增量、评价成本和不可行率计算奖励。
11. 主流程串行更新Q表，并调用原NSGA-II完成环境选择。

## 2. Q-learning保留条件

Q-learning目前是待验证控制器，不是已经成立的创新结论。后续首先开展多状态Oracle分析：

- 如果不同事件、阶段、严重程度和预算对应不同优选动作，并且Q-learning优于Best-fixed或规则控制器，则保留Q-learning复合决策；
- 如果固定动作长期接近Oracle，则收缩为可解释的规则预算控制器，不强行增加强化学习复杂度。

## 3. 完整消融计划

| 编号 | 方法 |
|---|---|
| B0 | 冻结动态baseline |
| B1 | 仅将原Q-learning/N1–N6接入动态事件 |
| B2 | B1加合法动作掩码 |
| B3 | B2加瓶颈Top-K区域 |
| B4 | B3加预算复合决策和质量–成本奖励 |
| B5 | 完整版本加并行候选评价 |

该消融用于区分动态接入、合法性、区域、预算控制和并行评价分别贡献了什么。

# 附录｜汇报时的四句简答

## 核心创新是什么？

在动态事件后的合法范围内识别瓶颈Top-K区域，并扩展Q-learning，使其联合选择合法邻域、区域规模和评价预算，以提高有限响应时间下的质量–时间效率。

## 相比原算法改了哪里？

不改变问题、染色体、解码器和NSGA-II主体，主要增加动态合法动作、瓶颈区域、预算感知复合决策和并行候选评价。

## 目前有什么证据？

单实例探针支持瓶颈小区域、预算权衡和并行评价值得继续研究，但尚未证明完整算法优于冻结baseline，也尚未证明Q-learning必须保留。

## 下一步是什么？

先完成A3复述验收，再开展多状态Oracle；通过后实现完整算法原型，并在A5–A6完成正式对照、消融和统计检验。
