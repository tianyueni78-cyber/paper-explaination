# LLM 离线邻域算子 MVP 报告

## 结论

本次 MVP 尚不能证明存在 1-2 个 LLM 候选在多个实例和 seed 上稳定优于 N1-N6。

四个候选全部通过语法/导入、三参数接口、`Chromosome.validate()` 和原动态解码，2,000 次候选 decode 的可行率为 100%，错误数为 0。这说明 LLM 可以离线生成与当前动态 FJSP-AGV 染色体和解码器兼容的新算子。性能方面只有 `llm_e1_order_agv` 出现可重复研究信号，但不足以形成稳定增益结论。

## 实验设置

- 动态事件：订单取消，`time=50`，取消工件 2；
- 实例：Mk02、Mk07；
- seed：11、22、33、44、55；
- 算子：N1-N6 与 4 个 LLM 候选；
- 每个实例-seed-算子：20 次真实 `_decode_dynamic`；
- 总预算：2×5×10×20 = 2,000 次候选动态解码；
- 策略边界：CS 型全染色体可变，未调用或改变在线 Q-learning；
- 接受规则：与原 QNSGA-II 一致，候选至少改善一个目标时成为下一父代；
- 目标：原解码结果的 `makespan` 与 `machine_energy`（当前 baseline 的 TEC 目标）；
- HV：每个实例-seed 内将十个算子的非支配结果统一 min-max 归一化，再复用 `hypervolume_2d`；
- 初始上下文 decode 不计入任何算子的候选预算，所有算子预算相同。

## 候选与 EoH 生成方式

| 候选 | EoH方式 | 参考父代 | 改动机制 |
|---|---|---|---|
| `llm_i1_machine_speed` | i1 | 无 | 联动机器选择与载货速度 |
| `llm_e1_order_agv` | e1 | N1/N2/N5 | OS 异工件交换并重分配一个 AGV |
| `llm_e2_machine_transport` | e2 | N3/N4/N5/N6 | 抽取机器-运输骨架后协同修改 MS/AS/空载速度 |
| `llm_m1_transport_rewrite` | m1 | N5/N6 | 将单 AS 改写扩展为同位置 AS/双速度改写 |

候选由本次 Codex 会话离线生成并固化。运行时不调用 LLM；完整代码、模型、seed、父代与验证结果保存在 `results/llm_operator_candidates.json`。

## 聚合结果

| 算子 | 平均最小 Makespan | 平均最小 TEC | 平均 HV |
|---|---:|---:|---:|
| N1 | 270.829 | 3291.198 | 0.8780 |
| N2 | 277.248 | 3305.698 | 0.7269 |
| N3 | 281.732 | 3292.098 | 0.6486 |
| N4 | 290.688 | 3329.175 | 0.4754 |
| N5 | 285.581 | 3361.218 | 0.4691 |
| N6 | 306.362 | 3437.394 | 0.1664 |
| `llm_i1_machine_speed` | 305.941 | 3426.559 | 0.1041 |
| `llm_e1_order_agv` | 275.349 | 3297.356 | 0.8797 |
| `llm_e2_machine_transport` | 307.818 | 3436.755 | 0.0720 |
| `llm_m1_transport_rewrite` | 288.399 | 3367.493 | 0.3861 |

相对每个实例-seed 中的最佳 N1-N6：

- `llm_e1_order_agv`：Makespan、TEC、HV 各严格胜出 2/10 次；
- `llm_m1_transport_rewrite`：HV 严格胜出 1/10 次，其余两目标为 0/10；
- 另两个候选三个指标均为 0/10。

`llm_e1_order_agv` 的平均 HV 为 0.8797，略高于 N1 的 0.8780，但其平均 Makespan 和 TEC 均弱于 N1。因此这只是后续候选改进方向，不是稳定优越性的证据。

## 回答研究问题

当前证据支持较弱命题：LLM 能离线生成结构不同、合法、可重复并能偶尔超过 N1-N6 的动态 FJSP-AGV 邻域算子。

当前证据不支持目标中的较强命题：至少 1-2 个候选在多个实例/seed 上产生稳定有效增益。第一阶段 MVP 的正确判定为“接口与可行性通过，性能门槛未通过”。

## 限制

- 只有两个实例、一类事件和 5 个 seed，不用于论文级统计结论；
- 每算子只有 20 次 decode，是筛选预算；
- 只测试 CS 型全染色体可变边界；
- 候选不是在线 selector，不能推断未来在线替代 Q-learning 的表现；
- 未选择有利运行，所有 100 行结果均保留在 CSV。
