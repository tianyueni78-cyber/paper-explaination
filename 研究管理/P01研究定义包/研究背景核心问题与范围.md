# 研究背景、核心问题与范围

## 1. 研究背景与应用场景

本研究面向静态柔性作业车间中机器与有限AGV的协同调度。工序不仅要选择可加工机器并满足工序先后关系，还要由有限AGV完成机器之间的运输；机器选择、加工顺序、AGV分配与运输时序相互影响。原论文以makespan和TEC为优化目标，并使用QNSGA-II求解该多目标问题。

本研究不重新证明“机器与AGV需要协同”这一既有事实，而是关注求解过程中的局部搜索资源分配：在真实完整解码需要消耗计算资源的条件下，应当修改哪些局部区域、使用哪一种邻域、为本次局部搜索投入多少次评价。

证据依据：原论文第13–31、77–168、411–516行；[P01证据来源登记表](P01证据来源登记表.md)S01–S03。

## 2. 核心研究问题

> 在相同累计真实完整解码预算下，平铺式Q-learning能否根据静态搜索状态，在36种`(K,N,b)`完整动作中有效选择局部区域规模K、邻域N和预算档位b，从而获得优于原始仅选N策略和随机三元策略、并接近或超过由开发数据确定的固定最佳配置的多目标搜索表现？

这个问题包含三个必须同时回答的层次：

1. **结果层**：A3在相同真实解码预算下是否改善HV、IGD、C-metric及最终Pareto质量；
2. **机制层**：动作是否随状态发生可解释变化，尤其是否真正学习了K和b，而不是只偏好某一动作；
3. **可学性层**：36动作在现有数据量与预算下是否获得足够访问，Q值是否稳定而非由少数偶然奖励决定。

若结果层没有优势，或机制与可学性证据不足，研究必须允许结论为“不支持平铺式三元Q-learning”，并据此转向结构化动作或版本B。

## 3. 操作性定义边界

| 概念 | P01暂定含义 | 后续冻结位置 |
|---|---|---|
| 状态 | 仅描述静态搜索过程，不含故障类型、事件阶段或动态扰动 | A3 P03-13；A5协议复核 |
| K | 允许邻域修改的Top-K候选区域规模 | A3 P03-28 |
| N | N1–N6之一，控制修改方式 | A2核对基础语义；A3定义受限语义 |
| b | 本次动作允许消耗的真实完整解码次数档位 | A3 P03-29；A5计费协议 |
| 总预算 | 所有内部和外部真实完整解码调用的累计次数 | A3 P03-18；A5 P05-11、17、30 |
| 有效 | 同预算下结果有实际意义的改善，且机制诊断不否定学习解释 | A5冻结指标和统计；A6执行 |

P01不自行填写K、b、状态阈值、重复数或显著性门槛。

## 4. 研究范围

### 纳入范围

- 静态机器–AGV协同调度；
- Brandimarte扩展静态实例及经A5冻结的开发、验证和测试划分；
- 原静态QNSGA-II、N1–N6、Top-K区域和`(K,N,b)`动作；
- 相同真实完整解码预算下的质量、机制和计算开销比较；
- A0原始选择、A1随机三元、A2固定最佳、A3平铺Q-learning和AO离线诊断。

### 排除范围

- 订单取消、机器故障、AGV故障及事件驱动重调度；
- IS、RS、CS动态策略和重调度稳定性指标；
- 深度强化学习、代理模型或预测筛选，除非以后作为新设计重新审批；
- 使用正式测试数据选择固定最佳配置或调参；
- 把AO有限动作集事后最佳称为全局最优；
- 将内部解码、Oracle试探或失败候选免费处理。

## 5. P01复核结论

- 背景、场景、核心问题和静态范围已经形成可检查文本。
- 核心问题允许正面、负面和证据不足三类结论，不预设Q-learning有效。
- 数值协议仍由A3和A5负责，P01不越权冻结。
