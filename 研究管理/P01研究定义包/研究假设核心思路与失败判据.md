# 研究假设、核心思路与失败判据

## 1. 核心思路

在保持静态问题模型、解码器、目标口径和NSGA-II主流程一致的前提下，把原Q-learning“只选择邻域N”的接口扩展为`a=(K,N,b)`：

- K选择当前允许修改的Top-K局部区域规模；
- N选择N1–N6中的一种修改方式；
- b选择本次局部搜索允许消耗的真实完整解码次数档位。

输入是决策时刻可获得的静态搜索状态和剩余预算；计算是合法动作掩码、探索/利用选择、区域受限邻域执行、完整解码计费、档案质量变化与Q更新；输出是更新后的种群或档案、剩余预算和可追溯的状态—动作—奖励日志。

## 2. 可证伪假设

| 假设 | 内容 | 支持证据要求 | 反对证据 |
|---|---|---|---|
| H1 区域信息有用 | 状态相关的K选择比固定区域或无区域区分获得更高单位真实解码收益 | 多实例、配对重复下区域消融有稳定增量，且关键操作未系统漏选 | Top-K无增量、区域过小导致质量或多样性下降 |
| H2 三元学习有增量 | A3在相同总真实解码预算下优于A0和A1，并接近或超过开发数据确定的A2 | HV/IGD/C-metric、效果大小和置信区间共同支持；不只由单实例驱动 | A3仅胜随机、不能胜A0或接近A2 |
| H3 动作可学习 | 36动作在关键状态获得足够访问，Q值不由少数异常奖励决定 | 低未访问率、关键状态动作有重复更新、种子间策略具有稳定结构 | 大量动作0/1次访问、Q值对单次奖励高度敏感 |
| H4 b选择反映状态 | 停滞、剩余预算和邻域类型变化会产生可解释的b分布 | 预注册状态分组下b分布变化，且单位预算收益合理 | 总是选择最大b或选择与状态无关 |
| H5 收益不是免费计算 | 质量收益在计入全部真实解码和Q-learning开销后仍具有实际意义 | 等解码预算主分析及墙钟开销次分析均完整报告 | 收益只来自更多尝试，或开销抵消质量收益 |

## 3. 版本A支持条件

版本A至少需要同时满足：

1. 相同总真实完整解码次数下，A3优于A0和A1；
2. A3接近或超过只由开发数据确定的A2；
3. 动作选择随状态发生可解释变化；
4. 大部分关键状态—动作获得足够访问；
5. 优势不是只来自一个b档位或个别实例；
6. 增加的学习开销没有抵消质量收益。

具体统计方法、置信水平和“接近”的容差由A5事前冻结，不能在看完测试结果后补定。

## 4. 失败判据与出口

| 失败现象 | 可得结论 | 后续出口 |
|---|---|---|
| 大量动作只访问0次或1次 | 36动作对现有数据与预算过大 | 转向分层、因子化或版本B |
| A3不优于A0 | 三元学习未产生可验证增量 | 停止性能主张，定位K/N/b各自问题 |
| A3优于A1但不及A2 | 学习复杂度没有超过固定配置价值 | 保留固定配置或简化策略 |
| 最大b几乎垄断且单位收益不高 | 奖励存在尝试机会偏置 | 重审奖励和预算控制，不把结果算作支持 |
| 策略随种子剧烈变化 | Q值不稳定或样本不足 | 增加诊断、简化状态动作，不事后挑选种子 |
| Top-K造成多样性损失 | 区域限制过强 | 扩大区域、保留探索通道或否定H1 |
| 质量改善但墙钟开销过大 | 方法可能有效但不具实际计算价值 | 收缩贡献，报告适用条件 |

## 5. 判定边界

- “实验按协议完成”与“方法假设得到支持”分别判定。
- 任一负面结果都必须保留；不能为保留版本A临时更换主要指标或测试集。
- AO只表示给定动作集合和已支付诊断评价下的事后参考，不是可部署算法或全局最优。
