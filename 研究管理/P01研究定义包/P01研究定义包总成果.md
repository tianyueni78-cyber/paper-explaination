## P01-01 研究背景与应用场景

### 交付成果

本研究面向静态柔性作业车间中机器与有限AGV的协同调度。工序需要选择可加工机器、满足工序先后关系，并由有限AGV完成机器之间的运输。机器选择、机器加工顺序、AGV分配和运输时序相互影响，任一环节的变化都可能改变工序开始时间、完工时间和能耗。

原论文建立了考虑有限运输资源的柔性作业车间调度模型，以makespan和TEC为优化目标，并使用QNSGA-II搜索Pareto解。当前研究保留静态问题、机器—AGV协同关系和多目标优化背景，把研究重点放在局部搜索资源的分配上：一次局部搜索应当修改哪个区域、使用哪个邻域、投入多少次真实完整解码。

应用场景是已经给定作业、工序、可选机器、加工时间、AGV及运输参数后，在生产开始前生成静态机器—AGV协同调度方案。不研究生产执行过程中的订单取消、机器故障和AGV故障。

### 依据

## P01-02 一个明确、可验证的核心问题

### 交付成果

核心问题为：

> 在相同累计真实完整解码预算下，平铺式Q-learning能否根据静态搜索状态，在36种`(K,N,b)`完整动作中有效选择局部区域规模K、邻域N和预算档位b，从而获得优于原始仅选择N策略和随机三元策略、并接近或超过由开发数据确定的固定最佳配置的多目标搜索表现？

这个问题分为三个检验层次：

1. 结果层：A3相对A0、A1和A2的HV、IGD、C-metric及Pareto质量表现；
2. 机制层：不同状态下K、N和b的选择是否发生可解释变化；
3. 可学性层：36动作是否获得足够访问，Q值是否稳定，而不是由少数偶然奖励决定。

比较对象固定为：

- A0：原始Q-learning，只选择N，K和b固定；
- A1：随机选择`(K,N,b)`；
- A2：使用开发数据确定的固定最佳`(K,N,b)`；
- A3：平铺式Q-learning直接选择`(K,N,b)`；
- AO：离线事后动作参考，只作诊断。

### 依据

- 原论文第461–473行：原动作集合为N1–N6。
- `Python-NEW/python_baseline/dfjspt/qlearning.py`：当前活动映射为4状态、6动作Q表。
- `Python-NEW/reproduction/14_论文级重复实验/静态最终审计与合并汇总.md`第48–64行：现有同目标消融未复现full优于随机邻域C。

### 通过标准

- 明确研究对象、比较对象、预算口径和评价方向；
- 能够通过实验得到支持、不支持或证据不足的结果；
- 不预设A3一定有效；
- 不使用正式测试数据选择A2。

### 当前判定

通过。

## P01-05 方法的核心思路

### 交付成果

在保持静态问题模型、解码器、目标口径和NSGA-II主流程一致的前提下，把原Q-learning“只选择邻域N”的决策接口扩展为`a=(K,N,b)`：

- K：选择允许邻域修改的Top-K局部区域规模；
- N：选择N1–N6中的一种修改方式；
- b：选择本次局部搜索允许消耗的真实完整解码次数档位。

完整工作过程为：

```text
解码当前候选并获得机器—AGV时间表
→ 提取静态搜索状态
→ 构造合法(K,N,b)动作集合
→ Q-learning选择动作
→ 在Top-K范围执行N邻域
→ 最多消耗b次真实完整解码
→ 计算档案质量变化与成本
→ 更新Q表、种群或档案及剩余预算
```

输入包括当前候选、机器—AGV排程信息、静态搜索状态、Q表和剩余总预算。输出包括新候选及其真实目标、更新后的种群或档案、Q表、剩余预算，以及状态—动作—奖励—解码计数日志。

### 依据

- 原论文第411–473行：Q-learning局部搜索的原始位置和N1–N6动作。
- `Python-NEW/python_baseline/dfjspt/qnsga2.py`：当前Q-learning嵌入NSGA-II的位置。
- P01-03的D01、D03、D07和D08。

### 通过标准

- 明确改进发生在原算法哪个位置；
- 明确输入、计算流程和输出；
- K、N、b各自作用不同且没有概念混淆；
- 所有内部真实完整解码都进入总预算。

### 当前判定

通过。

## P01-09 方法可能失败的条件

### 交付成果

| 失败条件 | 判定含义 | 对研究路线的影响 |
|---|---|---|
| 大量动作只访问0次或1次 | 36动作对现有数据与预算过大 | 转向分层、因子化动作或版本B |
| A3不能优于A0 | 三元学习没有产生可验证增量 | 停止版本A性能主张，定位K/N/b问题 |
| A3优于A1但明显不及A2 | 学习复杂度没有超过固定配置价值 | 保留固定配置或简化策略 |
| 最大b长期垄断且单位收益不高 | 奖励存在尝试机会偏置 | 重新检查奖励和预算控制 |
| 动作策略随种子剧烈变化 | Q值不稳定或数据不足 | 简化状态动作，不能挑选有利种子 |
| Top-K导致多样性或质量下降 | 区域限制过强或遗漏跨资源修改 | 扩大区域、保留探索通道或否定区域假设 |
| 质量改善被墙钟开销抵消 | 方法可能有质量收益但缺少实际计算价值 | 收缩适用范围和贡献表述 |

- P01-03的D04、D07和D08。
- P01-04的H1–H5反对证据。

### 通过标准

- 失败条件覆盖结果、机制、可学性和计算开销；
- 失败条件能够通过实验观察；
- 每种失败都有对应的结论或退出路线；
