# 创新方案冻结规格 v1.0

- 冻结日期：2026-08-28
- 状态：设计冻结，证据未冻结
- 适用范围：动态机器–AGV协同调度的局部搜索改进
- 版本规则：文字澄清升级为v1.x；研究问题、四模块、状态/动作/奖励主结构变更时必须新建v2.0，不覆盖本文档。

## 1. 暂定题目

**基于瓶颈感知与计算预算自适应局部搜索的多目标动态机器–AGV协同调度方法**

Q-learning进入最终题目的前提：多事件Oracle和正式消融实验支持其自适应必要性。

## 2. 研究问题

原静态QNSGA-II通过Q-learning从N1–N6中选择邻域操作，主要回答“怎样修改染色体”。它没有系统地将动态事件后的合法重调度边界、资源瓶颈、局部区域规模和有限计算预算纳入同一决策过程。

本研究回答：

> 在不改变问题模型、动态场景、染色体、解码器、目标函数和NSGA-II主体的前提下，如何使有限计算预算优先用于动态事件后合法且高价值的局部区域，以提高质量–时间效率和动态响应能力？

## 3. 原算法与事实边界

### 3.1 静态原算法

```text
NSGA-II全局演化
＋ Q-learning从N1–N6选择局部邻域
＋ 机器–AGV领域解码器评价
```

N1–N6是“怎样修改”的邻域类型，不是小/中/大搜索范围。

### 3.2 动态MATLAB观察事实

- 订单取消活动路径只使用N1。
- 机器故障和AGV故障活动路径的Q-learning邻域块被注释。
- 因此，“三类动态事件统一使用4×6 Q-learning”是待验证扩展，不是原MATLAB动态baseline的既成事实。

## 4. 冻结的四个改动

### 4.1 事件约束下的合法动作空间

确定性规则识别订单取消、机器故障和AGV故障，继承已完成/在制任务与资源状态，得到fixed、residual、可修改基因片段和合法邻域子集。安全约束由确定性规则保证，不交给Q-learning试错。

### 4.2 瓶颈感知的合法局部区域

从同一baseline解码结果中诊断机器加工压力或AGV运输压力，在residual中按瓶颈贡献生成Top-K局部区域。区域回答“具体修改哪些工序”，与N1–N6回答的“如何修改”分离。

### 4.3 预算感知的Q-learning复合动作

Q-learning保留，拟将动作从单纯邻域类型扩展为：

```text
复合动作 = 合法邻域N1–N6子集 × 区域规模 × 候选评价预算
```

状态候选信息包括事件类型/阶段、瓶颈类型/严重程度、搜索停滞和剩余预算。Q-learning是拟实现机制；其相对固定规则的必要性仍须实验证明。

### 4.4 保持结果一致的并行候选评价

候选染色体生成后，并行调用同一动态解码器计算Makespan和TEC。候选生成、Q表更新、种群合并和NSGA-II环境选择保持主流程串行。该模块为效率增强，不单独承担解质量创新主张。

## 5. 三类事件的统一框架与不同策略

| 事件 | 必须继承/限制 | 优先诊断 | RS下主要可调内容 | 候选搜索方向 |
|---|---|---|---|---|
| 订单取消 | 删除指定订单并重建剩余任务索引 | 删单后机器/AGV负载失衡 | OS、AS、VS，MS按baseline策略继承 | 顺序、AGV和速度调整 |
| 机器故障 | 故障区间不得使用该机器 | 故障影响范围、替代机器压力 | 故障机后续受影响工序的MS，以及OS、AS、VS | 换机、重排序和机器–AGV协调 |
| AGV故障 | 继承位置、电量、载货状态和修复时间 | 运输积压、等待、电量与位置 | MS按baseline策略继承，OS、AS、VS可调 | AGV重新分配、顺序与速度协调 |

三类事件共用“事件识别→合法边界→瓶颈诊断→区域生成→动作选择”框架，但不共用完全相同的合法动作集。

## 6. 必须保持一致

- 问题模型、调度假设和三类动态事件定义。
- 实例、资源、距离、加工时间、能耗与电池数据。
- 染色体表示及OS、MS、AS、VS等片段定义。
- 冻结后的同一机器–AGV领域解码器。
- Makespan与TEC定义。
- fixed/residual、在制任务和资源状态继承规则。
- NSGA-II的初始化协议、选择、交叉、变异、非支配排序、拥挤度和精英保留。
- 公平对照中的实例、种子策略、运行次数、预算和指标。

## 7. 第一版明确不做

- 不把Q-learning替换为PPO、DQN或其他深度强化学习。
- 不修改问题模型、数据、目标函数或解码器。
- 不加入预测模型、数学求解器精确修复或新业务场景。
- 不改变NSGA-II主体。
- 不以并行评价替代算法质量对照。

## 8. 拟实现流程

```text
动态事件
  → 继承任务与资源状态
  → 确定fixed/residual与合法动作集
  → 从原解码结果诊断资源瓶颈
  → 生成合法Top-K局部区域
  → Q-learning选择邻域＋区域规模＋评价预算
  → 生成候选染色体
  → 并行调用原动态解码器
  → 计算Makespan、TEC、质量改善与计算成本
  → 串行更新Q表
  → 与当前种群合并并执行NSGA-II环境选择
```

## 9. 冻结主张与待验证主张

### 已冻结的研究方向

- 主创新层次：动态局部搜索决策层与执行层。
- 主要效果方向：有限预算下的质量–时间效率与动态响应能力。
- 次要方向：目标质量和运行稳定性，以正式实验为准。

### 尚未证实

- Q-learning是否优于Best-fixed或可解释规则控制器。
- 早/中/晚事件、不同事件类型是否选择不同复合动作。
- 完整方法是否显著优于冻结baseline。
- 收敛速度、解集多样性和稳定性是否改善。

## 10. 正式消融架构

| 编号 | 方法 |
|---|---|
| B0 | 冻结的原动态baseline |
| B1 | 同规模随机区域 |
| B2 | 固定Top-K瓶颈区域，固定预算 |
| B3 | 瓶颈区域＋预算规则控制，不使用Q-learning |
| B4 | 瓶颈区域＋预算感知Q-learning |
| B5 | B4＋并行候选评价 |

主对照使用相同墙钟预算；补充对照使用相同完整解码/目标评价次数。
