# 证据与实验台账

> 本文档保留历史，不删除旧实验。新方法、新配置或新指标必须新建实验编号，不得覆盖原结论。

## 证据等级

| 等级 | 含义 |
|---|---|
| P0 | 想法或尚未运行的设计 |
| P1 | 单实例、少量状态的可行性探针 |
| P2 | 冻结 baseline 下的多实例、多种子或多事件证据 |
| P3 | 公平对照、消融、统计检验完整，可进入论文主结论 |
