# 实验结果价值判定

## 1. 文档目的与适用范围

本文档用于说明：

1. 新方法的质量、时间等指标发生不同变化时，应如何判断其研究价值；

实验价值应由方法主张、主要指标、计算成本、结果稳定性和适用边界共同判断。

## 2. 创新性与实验有效性是两个问题

判断一个研究方案时，需要分开回答：

1. **机制是否具有新意**：是否提出了已有方法中没有或并非显然可得的机制；
2. **机制是否具有实证价值**：实验是否表明它在质量、时间、稳定性、资源消耗或适用范围上带来有意义的收益；
3. **证据是否支持具体主张**：实验结果只能支持与实验设计和指标一致的结论。

提出新机制不等于该机制必然有效。无效或负向实验仍然可以帮助排除方案、定位问题，但不能据此把该机制写成已经获得支持的主要贡献。

## 3. 不同实验结果的含义

| 实验结果 | 能否认为有价值 | 可以支持的表述 |
|---|---|---|
| 质量提高、时间减少 | 最强结果 | 同时提高搜索效果和计算效率 |
| 质量提高、时间基本不变 | 可以 | 在相同计算成本下提高解集质量 |
| 质量基本不变、时间减少 | 可以 | 在保持解集质量的情况下减少计算成本 |
| 质量大幅提高、时间略有增加 | 可以 | 通过可接受的额外计算成本换取明显的质量提升 |
| 质量略有下降、时间大幅减少 | 可能可以 | 提供一种可调节的质量—时间折中 |
| 质量大幅下降、时间略有减少 | 通常不支持 | 成本节省通常不足以补偿质量损失 |
| 一些实例改善、一些实例下降 | 不能直接下结论 | 需要分析适用条件，并报告不同实例上的胜、平、负分布 |
| 平均值改善但结果波动很大 | 证据不足 | 需要增加独立重复运行，并分析统计不确定性 |
| 所有关键指标基本不变 | 通常缺少实证价值 | 除非方法明显简化了实现、数据需求或部署条件 |
| 质量下降、时间增加 | 不支持 | 当前方法被基线方法支配 |

## 4. Pareto支配与质量—成本折中

假设解集质量越高越好，计算时间越低越好：

```text
质量
 ↑                 新方法甲
 |                 ● 质量更高且速度更快
 |
 |       原方法 ●
 |
 |   新方法乙 ●      速度更快但质量略低
 +----------------------------→ 时间
       快                     慢
```

可以按照以下关系判断：

- 如果新方法的质量更高、时间更短，则新方法支配原方法；
- 如果新方法的质量更高，但时间也更长，则两种方法互不支配，需要判断增加的时间是否值得；
- 如果新方法的质量略有下降，但运行时间大幅减少，也可能形成有价值的质量—时间折中；
- 如果新方法的质量更低且运行时间更长，则新方法被原方法支配，当前版本没有保留理由。

因此，新方法不需要让所有指标同时改善。更合理的最低要求是：

> 在主要指标没有出现不可接受退化的前提下，至少一个重要指标获得稳定、可复现且具有实际意义的改善。

其中：

- **主要指标**：HV、IGD、C-metric、最终非支配解集质量等；
- **不可接受退化**：需要在查看正式实验结果之前规定允许的下降边界，不能根据结果临时调整；
- **重要指标**：实际运行时间、完整解码次数、候选可行率、结果稳定性和内存消耗等；
- **稳定改善**：改善不能只出现在少数实例或单次随机运行中；
- **具有实际意义**：即使差异在统计上可以识别，幅度过小也未必具有实际研究价值；
- **可复现**：使用不同随机种子、多个代表性实例和合理搜索预算时，仍能观察到相同趋势。

## 5. “质量基本不变”的判定要求

不能仅凭两个平均值接近，就宣称质量基本不变。应预先设置可接受退化界限，例如：

\[
\frac{HV_{\mathrm{new}}-HV_{\mathrm{base}}}
{HV_{\mathrm{base}}}
\geq -\varepsilon
\]

其中，\(\varepsilon\) 表示允许的最大相对退化比例。

只有当以下条件同时满足时，才可以表述为“质量基本不变”：

1. 允许的退化界限在查看正式实验结果前确定；
2. 该界限具有领域依据或实际成本依据；
3. 多次独立运行的不确定性分析支持退化没有超过该界限；
4. 结论在多个代表性实例上基本成立。

例如，若预先规定允许HV最多下降1%，并且重复实验结果支持实际下降不超过该范围，则可以表述为：

> 在预设质量容忍范围内保持解集质量，同时减少候选评价次数或实际运行时间。

不能为了使实验结果达到通过条件，在观察结果后随意放宽退化界限。

## 6. 推荐的质量—成本比较方式

不应只比较单一预算下的最终结果。建议为每种方法设置多个实际时间或完整解码预算，例如：

\[
10,\ 20,\ 30,\ 50,\ 100
\]

次完整解码，并绘制HV或IGD随实际时间、完整解码次数变化的曲线。

重点检查：

- 在相同运行时间下，哪种方法获得的解集质量更高；
- 达到相同解集质量时，哪种方法消耗的时间或解码次数更少；
- 方法是否只在小预算阶段有效；
- 随着预算增加，方法优势是否保持、消失或反转；
- 不同规模和不同特征的实例是否具有一致趋势。

如果新方法的质量—成本曲线在大部分预算区间优于基线，可以支持较强的效率改善结论。

如果新方法只在严格的小预算条件下具有优势，则应限制结论范围，例如：

> 该方法适用于计算预算严格受限条件下的快速近似搜索。
