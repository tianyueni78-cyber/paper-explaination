# 预期贡献与实际贡献分开

## 结论

当前已经完成的是研究定义与证据边界，不是算法效果贡献。预期贡献必须等后续文献、实现和实验分别提供证据后，才能转化为最终贡献。

| 层级 | 内容 | 当前状态 |
| --- | --- | --- |
| 已完成成果R1 | 冻结了可运行、可重复且与创新隔离的静态A0 | 已由P02完成 |
| 已完成成果R2 | 形成了A0局部搜索控制的行为诊断、核心问题和可证伪假设 | P03形成 |
| 预期贡献C1 | 利用完整机器–AGV排程反馈构造Top-K关键区域 | 待P04新颖性核验、方法实现和区域消融 |
| 预期贡献C2 | 用Q-learning联合选择`(K,N,b)` | 待可学性、固定策略和随机策略对照 |
| 预期贡献C3 | 建立按真实完整解码统一计费的搜索资源比较与机制诊断 | 待协议冻结和正式实验 |
| 最终论文贡献 | 只保留被文献差异、代码、消融、统计与机制证据共同支持的内容 | 尚未形成 |

如果Top-K无增量、联合动作不可学习或质量收益来自额外计算，相应预期贡献必须收缩或删除；A0冻结和负面诊断仍可作为研究过程成果，但不能包装成新算法有效性。
