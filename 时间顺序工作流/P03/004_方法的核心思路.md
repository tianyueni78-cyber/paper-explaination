# 方法的核心思路

## 结论

创新只发生在A0局部搜索资源分配与学习控制阶段：先从一次真实完整解码得到的机器与AGV排程反馈中识别候选瓶颈并形成Top-K可修改区域，再由Q-learning选择`(K,N,b)`，决定搜索哪里、使用哪个N1–N6邻域以及本次最多支付多少次真实完整解码。

## 输入、处理与输出

| 环节 | 内容 |
| --- | --- |
| 输入 | A0当前种群或档案、完整排程反馈、搜索进展、剩余真实解码预算 |
| 区域定位 | 对机器与AGV排程中的瓶颈证据排序，构造Top-K合法候选区域 |
| 动作选择 | 在剩余预算允许的动作中由Q-learning选择`(K,N,b)` |
| 邻域执行 | N保持N1–N6基本修改语义，只把允许修改对象限制在所选区域 |
| 真实评价 | 每个进入正式比较的候选都运行A0同一完整解码器；预测值不进入Pareto档案 |
| 计费 | 初始化、子代、邻域内部试探和最终候选的每次真实完整解码统一扣减 |
| 学习反馈 | 根据档案或种群的质量变化与实际成本形成奖励并更新Q表 |
| 输出 | 更新后的种群/档案、剩余预算、状态—动作—奖励—Q更新—解码计数日志 |

A0的五段染色体、40/30/30初始化、完整解码、遗传操作、NSGA-II选择、Makespan、TEC及N1–N6基本语义保持不变。P03只固定创新位置和信息流，不提前固定状态特征、K档位、b档位、奖励公式和Q表生命周期；这些属于后续方法合同。
