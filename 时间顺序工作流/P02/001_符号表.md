# 符号表

## 集合与索引

| 符号 | 含义 |
|---|---|
| $i,d,k$ | 工件索引 |
| $j,h,f$ | 工序索引 |
| $m$ | 机器索引 |
| $a$ | AGV索引 |
| $N$ | 工件数量 |
| $M$ | 机器数量 |
| $A$ | AGV数量 |
| $O_i$ | 工件$i$的工序数量 |
| $O_{ij}$ | 工件$i$的第$j$道工序 |

## 加工与完工时间

| 符号 | 含义 |
|---|---|
| $t_{ijm}$ | 工序$O_{ij}$在机器$m$上的加工时间 |
| $C_i$ | 工件$i$的完工时间 |
| $C_m$ | 机器$m$的完工时间 |
| $C_{max}$ | 最大完工时间 |
| $T^s_{ijm}$ | 工序$O_{ij}$在机器$m$上的加工开始时间 |
| $T^e_{kfm}$ | 工序$O_{kf}$在机器$m$上的加工结束时间 |
| $T^e_{i,j-1,m}$ | 工件$i$的前一道工序$O_{i,j-1}$的加工结束时间 |

## AGV运输与充电

| 符号 | 含义 |
|---|---|
| $T^{l,s}_{ija}$ | AGV $a$运输工序$O_{ij}$的载货开始时间 |
| $T^{l,e}_{ija}$ | AGV $a$运输工序$O_{ij}$的载货结束时间 |
| $T^{u,s}_{dha}$ | AGV $a$执行工序$O_{dh}$运输任务前的空载开始时间 |
| $T^{u,e}_{ija}$ | AGV $a$运输工序$O_{ij}$前的空载结束时间 |
| $t^{m\to c}_a$ | AGV $a$从机器$m$到充电区的运输时间 |
| $t^{charge}_a$ | AGV $a$的一次充电持续时间 |
| $T^{charge}_a$ | AGV $a$的充电开始时间 |
| $TQ_a$ | AGV $a$的最高电量阈值 |
| $LQ_a$ | AGV $a$的最低电量阈值 |
| $Q^{l,e}_{ija}$ | AGV $a$完成工序$O_{ij}$载货运输后的电量 |
| $Q^{u,s}_{kfa}$ | AGV $a$开始下一空载运输时的电量 |
| $P^u_a$ | AGV $a$的单位时间空载运输能耗 |
| $P^l_a$ | AGV $a$的单位时间载货运输能耗 |
| $P^{charge}_a$ | AGV $a$的充电速率 |

## 机器能耗

| 符号 | 含义 |
|---|---|
| $P^{busy}_m$ | 机器$m$单位加工时间能耗 |
| $P^{idle}_m$ | 机器$m$单位空闲时间能耗 |
| $E_{busy}$ | 所有机器的加工能耗 |
| $E_{idle}$ | 所有机器的空闲能耗 |
| $TEC$ | 机器总能耗，$TEC=E_{busy}+E_{idle}$ |

## 二元变量

| 符号 | 含义 |
|---|---|
| $x_{ijm}$ | 工序$O_{ij}$由机器$m$加工时为1，否则为0 |
| $y_{ija}$ | 工序$O_{ij}$由AGV $a$运输时为1，否则为0 |
| $w_{ija}$ | AGV $a$运输工序$O_{ij}$后需要充电时为1，否则为0 |

## 排程编码记号

| 记号 | 含义 |
|---|---|
| OS | 工序排序片段 |
| MS | 机器选择片段 |
| AS | AGV选择片段 |
| SS | AGV速度选择片段；分别记录每道工序空载与载货运输的速度档位 |
