# 条件动作景观与可预测性 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成可复核的24动作条件景观，检验可重复Oracle和决策前3近邻是否超过训练集选择的固定动作。

**Architecture:** 新实验只读导入冻结A0，并复用S0的解码计费、区域A和单动作试验。采集脚本只负责生成状态与原始动作结果；分析脚本只读取结果并执行留一实例比较；审计脚本独立检查配对、共享前缀、计费、泄漏和来源哈希。

**Tech Stack:** Python 3.13标准库、冻结`paper_static_baseline`、`unittest`。

**Spec:** `时间顺序工作流/P05/条件动作景观实验/01_实验协议.md`

## Global Constraints

- 不修改原MATLAB和冻结A0。
- 不新增第三方依赖。
- 全部真实完整解码计费；Oracle只作离线诊断。
- 输出目录拒绝覆盖，超时不自动重试。
- 先看测试失败，再写最小实现。
