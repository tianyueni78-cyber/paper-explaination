# 第三轮控制核心实现与测试结论

## 结论

确认机制的零解码控制核心已经实现，行为测试通过。它证明代码能按照合同生成K候选、掩码N、分批释放b、计算和更新分解Q、执行置信门控并衰减旧状态信用；不证明机制能提升HV、Makespan或TEC。

## 已实现内容

| 模块 | 实现行为 |
|---|---|
| K | A50只有带来足够边际覆盖或新增机会时才进入候选 |
| N | 只保留动作前机会数大于0的N1—N6 |
| b | Q选择4/8/12最高额度，执行中以4次为一批继续或停止 |
| Q | `QK+QN+Qb+QKN+QNb`，不含`QKb`；TD改变量在五项间均分 |
| 门控 | 至少两个动作且Q值差达到阈值才返回自适应动作 |
| 生命周期 | 只衰减发生显著变化的旧状态信用 |
| 合同 | 协议改变、打开保留数据或启用`QKb`都会被拒绝 |
