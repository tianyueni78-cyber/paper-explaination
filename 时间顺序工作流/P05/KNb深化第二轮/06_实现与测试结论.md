# 实现与测试结论

## 结论

K*、N*、b*的最小局部搜索原型已经实现，19项测试通过；修复版24条冒烟轨迹及逐候选核验、完整回放通过。**这证明本轮局部实验入口具备工程运行依据，不证明任何模块改善算法性能。** 原A0与MATLAB未修改，未读取Mk07/Mk08数据内容。

## 实现

- [mechanisms.py](scripts/mechanisms.py)：区域排序、四状态、邻域近期信用、深度规则。
- [run_experiments.py](scripts/run_experiments.py)：连续局部搜索、真实解码计费、严格过滤、分离随机流、失败轨迹保存、来源校验。
- [test_mechanisms.py](scripts/test_mechanisms.py)、[test_runner.py](scripts/test_runner.py)：机制与运行边界测试；另保留4项旧诊断测试。
- [audit_smoke.py](scripts/audit_smoke.py)：独立矩形条带HV重算、候选目标重新解码与轨迹回放。

冻结协议与实现逐字段核对；改变未支持的参数会拒绝运行，不把JSON写了参数却未生效当有效配置。输出目录已存在时拒绝覆盖。

## 重现命令

在本目录执行：

```powershell
python -X utf8 -B -m unittest discover -s scripts -p 'test_*.py'
python -X utf8 -B scripts/run_experiments.py --stage smoke --output runs/smoke-replay-new
python -X utf8 -B scripts/audit_smoke.py runs/smoke-v3
```

需要现有工作区中的冻结Python A0以及相邻旧探索脚本/数据；本文件夹不是独立可搬移安装包。不新增第三方依赖。
