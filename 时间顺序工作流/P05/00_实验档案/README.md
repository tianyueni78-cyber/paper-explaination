## 状态词含义

| 状态 | 含义 |
|---|---|
| 已完成 | 冻结范围内的运行、分析和记录齐全；结果可以是正面或负面 |
| 部分完成 | 已保存真实运行，但没有完成冻结样本或配对，不能作最终效果判断 |
| 仅设计 | 只有规格或计划，没有代码、原始运行和实验结果 |
| 有限支持 | 存在局部信号，但未稳定超过强对照或证据不精确 |
| 不支持当前实现 | 已测试的具体规则没有达到其预定主张，不外推到所有同类方法 |
| 未决 | 现有实验没有直接回答，必须补充区分性实验 |
