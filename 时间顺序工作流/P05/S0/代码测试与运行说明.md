所有新代码位于本目录scripts，原始MATLAB和冻结A0未修改。运行依赖Python标准库及已有paper_static_baseline代码；本轮Python为3.13.9，Windows 11。

A0来源：Python-NEW提交b834c1b172a49e3df4148ecf8c26e6dc065baa15。默认查找工作区_codex_worktrees/Python-NEW-paper-static-baseline-v1；在其他位置运行需设置P05_BASELINE为该仓库绝对路径。不要替换成未核对的最新提交。

在本S0目录打开PowerShell：

```powershell
python -B scripts/test_probe.py
python -B scripts/test_analysis.py
python -B scripts/test_audit.py
python -B scripts/probe.py --smoke --output runs/smoke-new
python -B scripts/probe.py --output runs/screen-new
python -B scripts/analyze.py runs/screen-new
python -B scripts/audit.py runs/screen-new
```

输出目录必须不存在，避免覆盖原始记录。计数钩子只在单进程上下文生效并恢复，不得并行共用。当前提交保留smoke-20260904及screen-20260904两轮数据。

## 文件内容

- probe.py：固定A0状态、区域与候选，真实解码计费、原始数据输出。
- analyze.py：E0汇总、分离重复E1、留一实例E2。
- audit.py：重新解码全部候选、独立HV核算、抽样重跑与折隔离检查。
- test_probe.py：5项；计费/恢复、区域工序映射、HV、可重复性、隔离。
- test_analysis.py：3项；训练重复排除、近邻预测、确定性平局。
- test_audit.py：1项；检出遗漏的N4/N6内部解码。
- manifest.json：源文件/输入/协议/探针哈希、种子、环境及实际总量。
- states.json：36个冻结诊断状态。
- raw_trials.jsonl.gz：全部试验及候选染色体、目标，可供逐解复核。
- trials.csv：含无变化、越界、重复、实际解码、收益及时间。
- analysis：逐实例/状态表、折成员和结论统计。
- audit.json：核验结果及数据文件SHA-256。
