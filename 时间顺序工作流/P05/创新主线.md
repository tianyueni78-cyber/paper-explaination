# P05创新主线

## 当前固定结论

本文只有一条不可擅自删除、替换或缩减的创新主线：

> 在冻结静态A0的局部搜索资源分配与学习控制阶段，根据完整排程反馈识别Top-K关键区域，由Q-learning联合选择`(K,N,b)`，决定搜索哪些区域、采用哪个N1—N6邻域，以及本次允许消耗多少次真实完整解码。

该主线由用户确认。后续允许增加结构、深化机制、调整候选取值和使用比例，但不得因为某个具体实现实验失败，就把主线缩减成固定K、固定N、固定b，或者删除Q-learning联合控制。

本文定位为新方法论文。创新发生在原QNSGA-II的局部搜索控制阶段，不重新发明整个调度模型和NSGA-II框架。

## 主线的输入、计算与输出

### 输入

- 当前完整排程及其Makespan、TEC和资源时序信息；
- 机器负载、AGV负载、加工等待、运输等待和瓶颈分布；
- 当前搜索进度、已用及剩余真实解码预算；
- 当前Q-learning知识及本轮可执行动作。

所有状态信息必须在动作执行前获得。动作执行后的收益不能倒灌为本次决策特征。

### 计算

1. 从完整解码排程中提取能够反映机器—工序—AGV耦合关系的状态反馈；
2. 根据状态识别关键操作或关键资源，形成Top-K候选区域；
3. 在N1—N6中选择与当前区域和排程结构匹配的邻域N；
4. 为本次局部搜索分配允许真实完整解码预算b；
5. 对产生的候选进行真实完整解码并计算Makespan与TEC；
6. 根据真实收益、真实成本和后续搜索反馈更新Q-learning；
7. 将接受的候选返回原QNSGA-II后续流程。

### 输出

- 本次选择的`(K,N,b)`；
- 本次真实解码消耗及有效、无修改、重复和失败候选记录；
- 经真实解码确认的局部改进解；
- 用于后续决策的Q-learning更新结果。

## K、N、b的固定含义

### K：在哪里搜索

K表示从完整排程反馈中选择的关键区域及其规模。它必须回答：哪些操作、机器或AGV最值得优先投入局部搜索资源？

后续可以深化区域评分、跨资源关联、Top-K比例、区域覆盖饱和度和区域随状态变化的方式，但K不能退化为与排程无关的固定随机区域。

### N：怎样搜索

N表示选择N1—N6中的哪个邻域。N1—N6的基本修改语义沿用A0，不把修改邻域本身冒充创新。

后续可以深化区域—邻域兼容性、动作可行性约束、分层选择或组合策略，但必须保留“根据当前状态选择N”的研究问题。

### b：投入多少真实搜索资源

b表示本次局部搜索允许消耗的真实完整解码次数，不是候选生成数、预测次数或免费Oracle次数。

后续可以深化固定档位、逐批追加、继续/停止、剩余预算约束和跨父解转移，但必须保留“根据当前状态分配真实解码资源”的研究问题。

## Q-learning在主线中的职责

Q-learning不是装饰性模块。它需要学习排程状态、区域K、邻域N、预算b和真实搜索结果之间的关系，并回答：相同动作为什么在不同排程状态下具有不同价值？

后续允许研究：

- 平铺联合动作或分层/因子化Q结构；
- 动作可行性掩码；
- 即时收益、真实解码成本和后续价值的奖励组合；
- 探索与利用策略；
- 父解变化后的信用衰减、重置与Q表生命周期；
- 低置信度时回退强固定策略。

这些属于待实验裁决的深化方向。任何回退策略只能作为安全出口和对照，不能取代KNb联合控制主线。

## 必须继承且不能作为创新修改的部分

- 静态问题范围；
- OS—MS—AS五段染色体；
- 混合初始化；
- 完整解码流程；
- Makespan及已冻结的TEC口径；
- 遗传操作；
- NSGA-II多目标选择；
- N1—N6的基本修改语义；
- 冻结A0的输入、实例和预算计费基础。

原MATLAB和冻结Python A0保持只读。所有创新代码必须与A0隔离，并能关闭新增模块恢复相应对照行为。

## 允许深化但必须经过实验裁决的内容

| 深化位置 | 可以改变的内容 | 必须回答的问题 |
|---|---|---|
| 状态 | 全局汇总、局部结构、资源—操作关联、历史反馈 | 动作执行前信息能否预测动作价值？ |
| K | 评分依据、区域组成、比例候选、动态范围 | 关键区域是否优于同规模强对照？ |
| N | 兼容关系、可行性掩码、分层选择 | 状态选择是否超过最佳固定邻域？ |
| b | 预算档位、逐批追加、停止和转移 | 相同总真实预算下是否提高最终收益？ |
| Q结构 | 联合、分层或因子化表示 | 是否超过简单规则与Bandit？ |
| 奖励 | 质量、成本、多样性和延迟价值 | 奖励是否与最终Pareto质量一致？ |
| 生命周期 | 初始化、更新、衰减、重置和跨状态继承 | 历史反馈何时有效、何时失效？ |
| 使用比例 | 启用条件、置信阈值、搜索阶段覆盖率 | 自适应应在什么状态和多大范围内介入？ |

候选取值、比例或公式可以根据开发证据调整，但必须先说明“原定义—问题证据—建议定义—验证实验”，经确认并写入冻结协议后才能修改正式算法行为。

## 论文逻辑链

| 环节 | 固定内容 |
|---|---|
| 原方法不足 | 局部搜索区域、邻域选择和搜索预算没有形成由完整排程状态统一驱动的资源配置机制 |
| 核心思想 | 让Q-learning联合控制`(K,N,b)`，把有限真实解码投入当前最有价值的区域和邻域 |
| 挑战1 | 完整排程信息丰富，但必须形成动作前可计算、可泛化的状态 |
| 挑战2 | K、N和b相互影响，不能把三个局部最优简单相加 |
| 挑战3 | 真实解码昂贵且反馈会随父解和搜索进程失效 |
| 方法模块1 | 完整排程驱动的关键区域与结构状态 |
| 方法模块2 | K—N—b联合或分层Q-learning决策 |
| 方法模块3 | 真实预算计费、信用生命周期与安全控制 |
| 预期贡献 | 在统一真实解码预算下，提高局部搜索资源配置的有效性，并解释何时、为何选择不同动作 |

## 当前证据状态

创新主线已经固定，不等于创新方法已经有效或合同已经冻结。

现有34,560条条件动作景观结果说明：有限KNb动作存在小幅事后条件机会，但当前12维状态和3近邻不能在未见实例上利用该机会。此前若干K、N、b具体实现也未达到冻结要求。

因此，当前需要深化的是状态—动作关系、联合控制结构和反馈生命周期，而不是删除K、N、b主线。后续每个新增机制必须拥有独立对照、消融和失败出口；某个深化模块失败时可以删除该模块，但不能据此自动删除整条用户确认主线。

## 主线变更规则

以下变化必须再次取得用户明确确认：

- 删除K、N或b中的任何一个研究维度；
- 把Q-learning替换为纯固定规则并作为最终主方法；
- 将创新移出原QNSGA-II局部搜索资源分配与学习控制阶段；
- 修改A0染色体、解码、目标、遗传操作或NSGA-II选择；
- 改变静态研究范围；
- 使用预测目标代替真实完整解码进入正式Pareto结果。

在没有上述明确确认时，所有创新设计、实验和论文写作均以本文件为主线边界。
