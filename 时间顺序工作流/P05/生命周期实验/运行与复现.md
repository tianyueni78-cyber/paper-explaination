# 生命周期实验运行与复现

## 正式命令

工作目录：`时间顺序工作流/P05/生命周期实验/scripts`

```powershell
python lifecycle_experiment.py run --output ..\runs\formal-v1
python lifecycle_experiment.py analyze --output ..\runs\formal-v1
python -m unittest -v test_lifecycle_experiment.py
```

正式运行耗时806.50秒，采集阶段记录60453次真实解码，局部搜索记录233654次真实解码。正式轨迹SHA-256为`c8e0d817882880a85f0140bdccea91e5ec15661e1331abab5d08ddee65afdcee`。

## 文件

| 文件 | 内容 |
|---|---|
| `protocol.json` | 冻结实例、种子、阶段、预算、指标和闸门 |
| `scripts/lifecycle_experiment.py` | 快照采集、配对运行、指标计算和分层Bootstrap |
| `scripts/test_lifecycle_experiment.py` | 阶段边界、检查点、实例统计单位和仓库定位测试 |
| `runs/formal-v1/manifest.json` | 环境、来源版本、计费、状态与哈希 |
| `runs/formal-v1/trajectories.jsonl.gz` | 2520条完整原始轨迹 |
| `runs/formal-v1/analysis.json` | 预注册指标、分阶段结果和闸门判定 |

输出目录拒绝覆盖。重复正式实验应使用新目录；不得覆盖`formal-v1`。
