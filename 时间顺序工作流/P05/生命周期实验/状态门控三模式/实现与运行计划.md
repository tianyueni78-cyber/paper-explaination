# 状态门控三模式影子实验 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现并运行F、U、T、R、Q五控制器的20代影子轨迹实验，在每条轨迹最多80次真实完整解码下判断状态门控及Q-learning是否产生可重复的局部预算分配增量。

**Architecture:** 新代码全部放在`生命周期实验/状态门控三模式/`，只读复用既有`probe_knb.py`中的冻结A0、解码器、邻域、HV和计数器，以及`KNb深化第二轮/scripts/run_experiments.py`的单批真实评价语义。纯控制逻辑与排程执行分离；先用单元测试关闭状态机、动作屏蔽、Q更新、计费和随机流，再依次运行冒烟、开发、验证和最终保留层。影子结果不写回A0，也不冒充完整优化器性能。

**Tech Stack:** Python 3标准库、`unittest`、`gzip/json/csv`文件记录；复用现有Python静态baseline，不增加依赖。

**Spec:** `时间顺序工作流/P05/生命周期实验/第三步_状态门控三模式实验设计.md`

## Global Constraints

- 当前研究只处理静态机器—AGV协同调度；不加入订单取消、机器故障、AGV故障或动态重调度。
- 原MATLAB、冻结Python baseline、已有P05脚本和历史运行均只读；运行前后核对A0来源SHA-256。
- 五控制器读取相同A0父解序列，局部结果不写回A0；每代至多一个联合动作。
- 每条20代轨迹的搜索预算上限为80次真实完整解码；N4/N6内部解码同样扣减。
- 诊断状态固定使用AGV等待排序区域A的前25%；动作K只改变实际搜索范围。
- 24个活动动作固定为`K∈{0.25,0.50} × N1—N6 × b∈{4,12}`；X模式使用`b=0`。
- 开发层为Mk01—Mk06各10个新种子；验证层为Mk07—Mk08各10个封存种子；最终保留层为Mk09—Mk10各20个封存种子。
- 只把真实解码后的目标加入局部Pareto档案；结构屏蔽不得调用解码器或读取候选目标。
- 输出目录拒绝覆盖；失败、超时、零收益和未用预算全部保留。
- 开发结果只能决定是否推进，不能作为独立泛化或整算法优越性结论。

## 预先声明的统计边界

- 主要判断严格按`R对F → Q对R → Q对U`顺序执行；前一闸门失败时不把后一比较提升为主要成功证据。
- Makespan、TEC、效率、无效候选和模式占用均为辅助结果，不因其中某项有利而替换累计归一化HV主指标。
- 当前每层样本量来自已批准探索协议和计算可行性，不宣称经过正式功效分析。必须报告区间宽度；区间跨0只表示证据不精确，不能解释成“证明无效”。
- Mk07—Mk08和Mk09—Mk10各只有两个外部实例，最多支持这些实例范围内的方向检查，不能外推全部静态机器—AGV问题。
- 实际采用所需的最小效果量留到完整优化器确认协议运行前冻结；影子实验不得从观察结果反推一个有利阈值。

def load_protocol():

    validate_protocol(value)

def validate_protocol(value):

    if observed != EXPECTED_STATIC:

def structural_mask(data, parent, schedule, region, actions):

- [ ] **Step 3: 实现精确决策语义**

F每代选`(0.25,N3,4)`；T在第0代选`(0.25,N3,12)`、第1—17代选`(0.25,N3,4)`、第18—19代不搜索；R在D选`(0.25,N3,4)`、H选`(0.25,N3,12)`、X不搜索；Q在D/H按`epsilon=max(0.05,1/sqrt(1+n_s))`从mask内选动作；U与Q共用同一Q语义但禁止因收益转X。核心更新固定为：

```python
def update(self, state, action_index, reward, next_state, next_allowed):
    future = max((self.values[next_state][i] for i in next_allowed), default=0.0)
    old_value = self.values[state][action_index]
    self.values[state][action_index] = old_value + self.alpha * (
        reward + self.gamma * future - old_value)
```

动作深度超过剩余预算时只把本批`allowance=min(action.depth, remaining)`截断，不创建新的动作编号，也不改变用于Q更新的原动作编号。

        changed = old.touched(parent, child, data.instance.operation_counts)

```python
def summarize_pair(rows, left, right, metric, samples, seed):
    paired = pair_by_run(rows, left, right, metric)
    by_instance = group_seed_differences(paired)
    per_instance = {name: fmean(values) for name, values in by_instance.items()}
    rng = random.Random(seed)
    names = sorted(by_instance)
    draws = []
    for _ in range(samples):
        sampled_names = [rng.choice(names) for _ in names]
        draws.append(fmean(fmean(rng.choice(by_instance[name])
                                    for _ in by_instance[name])
                           for name in sampled_names))
    draws.sort()
    return make_summary(per_instance, draws)
```
