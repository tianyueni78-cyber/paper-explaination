# 区域—邻域匹配结论：整体小幅改善，未证明强区域需要匹配控制

条件化N选择在新验证平均值上超过全局固定N，但在Mk03不如打乱标签对照；在A与L区域，条件规则本身就退化为固定N3。因此不能把整体小正差写成“跨资源区域必须联合选择邻域”。

| 新验证实例 | 条件N | 固定N | 打乱标签N |
|---|---:|---:|---:|
| Mk03 | 0.000269157 | 0.000266871 | 0.000271963 |
| Mk06 | 0.000322747 | 0.000305278 | 0.000310805 |
| 均值 | 0.000295952 | 0.000286075 | 0.000291384 |

指标为真实HV增量/额度8。规则只用探索数据选择。固定N为N3；条件表如下：

| 区域 | K=25% | K=50% |
|---|---|---|
| R随机 | N5 | N3 |
| S机器 | N5 | N5 |
| A单AGV | N3 | N3 |
| C等权 | N3 | N3 |
| W等待 | N5 | N3 |
| L关联 | N3 | N3 |

拆分后：R/S有所收益，W反而降低；A/C/L相对固定N3完全相同。不能把弱区域获益借给主候选L。

## 阶段差异

验证第0/9/19代的条件N效用分别为0.000446005、0.000289302、0.000152550；固定N为0.000411264、0.000282594、0.000164365。后段条件N更差，说明用一个贯穿全程的条件表可能不合适，但尚未验证阶段化控制。

训练没有用验证标签；审计还会把验证标签改成极大值，确认拟合规则不改变。这是训练隔离检查，不是泛化成功证明。打乱仅用一次预定种子719，是负对照，不是完整置换显著性检验。
