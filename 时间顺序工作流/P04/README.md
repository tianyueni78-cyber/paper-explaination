# P04｜定向文献与创新性核验

## 节点目标

围绕静态机器—AGV协同调度和拟议的`(K,N,b)`联合控制，形成可追溯的检索、最近邻比较、创新边界、规范引文库和正式baseline选择。P04只回答“已有研究做到了什么、本文与其有什么可检验差异、实验必须和谁比”，不提前冻结P05的新算法细节。

## 本节点使用的Skill

- 执行：`scheduling-review`，用于检索分类、证据层级和可比性判断；`zotero:Zotero`，用于只读盘点本地文献附件；`static-machine-agv-research`，用于保持静态范围、A0身份和创新隔离。
- 验收：`academic-research-suite`中的来源核验、综合和Devil's Advocate规则，用于检查引用真实性、主张强度、反例及“未检出不等于创新”。

## 交付物

001—015号文件分别回答15项验收问题；`P04_关键文献库.bib`是可导入引文库；`P04_95篇DOI核验结果.json`和脚本构成机器可复核证据；`P04_独立验收报告.md`和`P04节点结论.md`给出闸门裁决。
