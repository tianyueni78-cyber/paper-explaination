# BibTeX和Zotero文献库

## 结论

P04已建立可导入的去重关键文献库[P04_关键文献库.bib](P04_关键文献库.bib)。本地Zotero继续作为全文附件入口，不把其当前44项直接视为规范书目库。

## 三源合并结果

- GitHub `paper`：29篇全文转换文本，提供原文证据；
- 本仓库：包含上述29篇的证据抽取，并扩展为95篇集中候选；
- Zotero：44项中41项为附件、3项为与本题无关的结构化期刊条目；相关附件与GitHub/本地文本存在重复。

去重优先级为DOI，其次arXiv号，再次规范化题名。BibTeX只收录P04论证直接使用的关键集，避免把未经全文核验的95篇全部包装成“已读文献”。后续写作引用新候选时，先补入BibTeX并再次核验稳定标识。

本轮未修改或批量导入用户Zotero，避免制造重复条目；如需要，可在写作阶段将该BibTeX人工或经明确授权导入Zotero。
