## 当前使用原则

- 任意时刻只允许一个节点处于“进行中”。
- 前序节点未通过，不启动后序节点。
- 每项成果只有一个首次验收节点。
- 每个节点必须同时提交逐项清单和中文结论文档。
- 每个节点采用“执行Skill＋独立验收Skill”双Skill分工。
- 生成成果文件只表示可验收；独立检查通过后才能勾选。
- 涉及代码的事项同时提交源代码、说明、测试、运行记录和版本信息。
- 节点通过后提供能力学习与就业迁移建议；该建议不作为科研验收证据。
