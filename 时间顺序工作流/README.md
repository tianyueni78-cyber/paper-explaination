## 当前使用原则

- 任意时刻只允许一个节点处于“进行中”。
- 前序节点未通过，不启动后序节点。
- 每项成果只有一个首次验收节点。
- 每个节点必须同时提交逐项清单和中文结论文档。
- 节点通过后提供能力学习与就业迁移建议；该建议不作为科研验收证据。
