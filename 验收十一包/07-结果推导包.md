## 七、结果推导包

每项结论都要有下面这条链：
```
原始结果
→ 指标计算
→ 统计观察
→ 排除替代解释
→ 支持或反对研究假设
→ 限定适用范围
→ 最终结论
```

需要分别回答：

- 实验观察到了什么
- 改善有多大
- 波动有多大
- 是否跨实例稳定
- 是否具有统计和实际意义
- 改善来自哪个模块
- 是否只是计算预算更多
- 是否只是某个参数档位更强
- 哪些替代解释尚未排除
- 哪些条件下方法失败
- 实验完成与方法有效分别判定
- 论文可以声称什么
- 论文不能声称什么
